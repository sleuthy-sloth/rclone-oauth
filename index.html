rclone-pi

This is a private, single-user OAuth client. It exists so that rclone — running on its owner's own Raspberry Pi — can read that same person's own Google Drive.

Specifically, it mounts one folder of the owner's Drive as a read-only library for a self-hosted audiobook server on the same machine.

  • One user: the account owner, who is also the developer of this client.
  • Not distributed, not offered as a service, no other users.
  • No analytics, no telemetry, no third-party services.
  • Data flows only between the owner's own device and the owner's own Google Drive.
  • The grant is read-only: drive.readonly.
